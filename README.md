## Dataset
We use the **GoEmotions** dataset by Google Research:

| Dataset | Source | Year |
|---|---|---|
| GoEmotions | Demszky et al., ACL 2020 | 2020 |

After preprocessing, the final dataset contains **58,008 Reddit comments** across **7 emotion categories** based on Parrot's emotion framework.

## Project Objective
To build a machine learning classifier that detects and categorizes emotions in Reddit comments into the following classes: Joy, Love, Surprise, Anger, Sadness, Fear, and Neutral.

## Installation
```bash
pip install -r requirements.txt
```

## Running the Scripts
Run the scripts in order from the root of the repository:
```bash
python scripts/01_load_data.py           # Downloads GoEmotions, applies Parrot mapping
python scripts/02_preprocess_data.py    # Cleans text, adds features
python scripts/03_basic_eda.py          # Generates EDA figures and summary table
python scripts/04_model.py              # Trains baseline models + best model
python scripts/05_imbalance_experiments.py  # SMOTE, LSA, class weight experiments
python scripts/06_genetic_algorithm.py  # Genetic Algorithm optimization (~50 min)
```

> **Note:** Raw data is automatically downloaded when running `01_load_data.py`. See `data/README.md` for details.
> **Note:** Script 06 takes approximately 50 minutes to run due to the Genetic Algorithm computation.
